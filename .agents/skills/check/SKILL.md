# 機械検証

1. `just check`を実行する。
2. greenの場合は「検証green」と各項目の結果を簡潔に報告する。
3. redの場合は、失敗した項目、一次情報から確認した原因、修正方針を報告する。修正が非自明なら方針の承認を得てから着手する。

`just check`は純ロジックとリポジトリ内の静的・単体検証だけを対象とする。マイク、システム音声、TCCの挙動は検証されないため、該当変更では人間によるローカル実機確認を別に記録する。
